# 项目执行规则（精简版）
1. 涉及 TODO / 提交 / 进度 / AI改动说明，必须触发 `ai-collab-governance`。
2. 每次任务结束，必须同步更新 `TODO.md`（状态变更：[ ]/[-]/[x]）。
3. 每次提交前，必须更新 `.ai-collab/CHANGELOG.md`（目标、改动文件、风险）。
4. 若有架构/流程变化，必须补一条 `.ai-collab/06-Journals/*.md`。
5. 提交信息格式：`type(scope): subject`。
6. 未完成 2~5 条时，不允许提交“完成”结论。
7. 默认先给“改动摘要 + 风险 + 明日计划”，再结束对话。
8. 若规则冲突，以本项目规则优先。
